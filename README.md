## 📋 Про проєкт

Метою проєкту було створення адаптивного, привабливого та зручного інтерфейсу для користувачів. Дизайн виконаний у темних тонах з акцентом на зображення продукції та фірмову типографіку. Сайт коректно відображається на всіх типах пристроїв: від мобільних телефонів до широких десктопних екранів.

## 🛠 Технологічний стек

У розробці використані сучасні підходи до верстки:

* **HTML5** — семантична розмітка для покращення SEO та доступності.
* **SCSS (Sass)** — використання препроцесора для структурування стилів, роботи зі змінними та вкладеністю.
* **Методологія BEM (Block Element Modifier)** — для організації CSS-класів, що забезпечує масштабованість та легку підтримку коду.
* **Flexbox** — для побудови гнучких сіток та вирівнювання елементів.
* **Mobile First** — стратегія верстки, де пріоритет надається мобільним пристроям з подальшою адаптацією під планшети та десктоп.

## ✨ Функціональні особливості

* **Адаптивність:** Повна підтримка мобільних пристроїв, планшетів та десктопів. Зміна розташування блоків (навігація, контакти) залежно від ширини екрану.
* **Інтерактивність:** Анімація при наведенні (hover-ефекти) на посилання, кнопки та іконки соціальних мереж.
* **Типографіка:** Використання підключених шрифтів для відповідності дизайн-макету.
* **Форми:** Стилізовані поля для вводу даних (наприклад, замовлення дзвінка або підписка).
